## Generation Tips

1. **Consistency**: Add "clay-like matte surface" and "chunky toy-like proportions" to maintain style
2. **Colors**: Use gradients rather than flat colors for depth
3. **Detail Level**: Request "simplified" forms - these are game assets, not sculptures
4. **Lighting**: Mention "soft shadows" for the characteristic look
5. **Scale Reference**: Models should work at roughly 1-2 unit height for characters, 2-3 for towers

## File Naming Convention

Save generated models as:
- `[name].glb` in the appropriate `/public/assets/models/[category]/` folder
- Ensure models are centered at origin with Y-up orientation
